# Conference Papers

Papers are organized by research track first. Venue-specific manuscripts live
inside each track.

- `meta-routing/dai2026/`: MetaRoute-Bench framework, artifact, operational evaluation, and deployment lessons
- `meta-routing/aaai2027/`: learned budget-aware routing method and executable-task evaluation
- `oracle2026/`: multilingual and culturally grounded routing evaluation

Shared implementation belongs in `src/metarouter`; paper folders must not
contain copied source trees. Each archival submission must have a distinct
research question, method, primary experiments, headline results, and conclusion.
